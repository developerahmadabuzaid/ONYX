## ما ليس في الكود (لا تفترضه)

- **Phase 2:** الأدوات التفاعلية (محلل SEO، وضع الأمان، مكتشف الفرص)، محرك المحتوى بالذكاء الاصطناعي. صلاحيات `Tools.*`/`ToolRuns.View` محجوزة بلا نقاط نهاية.
- **Phase 3:** AI Advisor، منصات الإعلانات، صفحات الأسواق.
- **Stage 5:** التصميم البصري (بعد موافقة المالك فقط). **Stage 13:** لم تبدأ.
- لا WhatsApp عام، لا تسعير عام، لا وكيل AI داخل هذا المستودع.
